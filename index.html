Tùy chọn nhập từ điển

Chọn phương thức nhập file.

Lưu ý:

  • Web thuần tĩnh nên cần nhiều RAM để xử lý Từ Điển. Không đủ RAM sẽ làm sập trình duyệt khi xử lý Từ Điển [Lớn]
  • Chỉ nhập file có đuôi .txt
  • Chức năng [Nhập nhiều file] yêu cầu chọn file theo đúng tên đã định nghĩa (ví dụ: Vietphrase.txt, Names.txt). Ấn nút nhập (4 nút xanh) thì không cần đúng Tên
  • Định dạng chung cho nội dung file là: [Tiếng Trung]=[Nghĩa Tiếng Việt], mỗi mục một dòng.
  • Bạn có thể tải file Từ điển tại: https://l.zxc.io.vn/vp

Chi tiết định dạng file:

  • Vietphrase.txt: File Vietphrase.
  • PhienAm.txt: (Phiên Âm) File này là từ điển ghi nghĩa của từng chữ tiếng Trung theo Hán Việt.
  • Names.txt, Names2.txt(nếu có): File chứa tên riêng.
  • LuatNhan.txt: File Luật Nhân có cấu trúc như ví dụ sau:

    不比{0}强=không mạnh bằng {0}
    Trong đó: {0} là tham số sẽ được hệ thống tự động thay thế theo dữ liệu từ điển..
    Lưu ý: Web chưa xử lý tốt Luật Nhân nên có thể gây lỗi NGHĨA từ điển

Các file tùy chọn khác (nếu có):

  • Pronouns.txt: File chứa đại từ nhân xưng.
  • Blacklist.txt: File này sẽ ghi lại các nội dung không cần thiết theo từng dòng để hệ thống có thể loại bỏ chúng trong quá trình dịch.
  • Babylon.txt: File từ điển Trung-Anh.
